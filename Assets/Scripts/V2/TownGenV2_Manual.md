## 1. 시작하기

### 윈도우 열기
- 메뉴: **TownGen V2 → Open Window**
- 단축키: **Alt+Shift+T**

### 첫 도시 만들기 (30초)
1. 윈도우의 **Create RoadGraph** 클릭
2. **Test Graphs → 5x5** 클릭 → 격자 도로 생성
3. **⚡ Build Blocks + Fill Buildings** 클릭 → 도시 완성

## 2. 핵심 개념

### 3단 파이프라인

**[Graph] ──build──→ [Blocks] ──fill──→ [Buildings]**
(노드+엣지) → (폴리곤 메쉬) → (박스)

| 단계               | 설명                             | 사용자 편집 |
| ------------------ | -------------------------------- | ----------- |
| **Graph**          | 도로의 노드와 엣지 (위상 정보)   | ✅ 직접 편집 |
| **Blocks**         | 그래프 face → 인셋된 폴리곤 메쉬 | ⚙️ 자동 생성 |
| **Buildings**      | 블록 안에 배치되는 빌딩          | ⚙️ 자동 생성 |
| **Regions** (선택) | 영역별 다른 빌딩 스타일          | ✅ 직접 편집 |

### 왜 이렇게 분리했나
- **Graph가 진짜 데이터**입니다
- 같은 그래프 + 같은 세팅 + 같은 Seed → 항상 같은 도시 (결정적)
- 그래서 그래프만 저장해도 도시 복원 가능
- Save 파일도 그래프 중심

## 3. 도구별 상세 설명

### 🤚 Move (Shift+Q)
노드 선택 + 이동.

| 입력                   | 동작                         |
| ---------------------- | ---------------------------- |
| 노드 클릭              | 선택 (노란 강조)             |
| 빈 공간 드래그         | 박스 선택                    |
| Shift+클릭             | 선택 추가/토글               |
| Shift+드래그           | 박스 선택 추가               |
| Position Handle 드래그 | 선택 노드들 일괄 이동        |
| Delete / Backspace     | 선택 노드 삭제 (연결 엣지도) |
| ESC                    | 선택 해제                    |

### ✏️ Draw (Shift+W)
도로 그리기.

| 입력                         | 동작                              |
| ---------------------------- | --------------------------------- |
| 클릭                         | 노드 추가 + 직전 노드와 엣지 연결 |
| 연속 클릭                    | 이어진 도로                       |
| 기존 노드 위 클릭            | 그 노드에 스냅 (재연결)           |
| 기존 엣지 위 클릭            | 엣지 분할 + 노드 삽입             |
| 드래그 시 기존 엣지 가로지름 | 자동 교차 노드 생성               |
| Shift (홀드)                 | 45° 각도 스냅                     |
| Ctrl (홀드)                  | 1m 그리드 스냅                    |
| ESC / 우클릭                 | 그리기 끊기                       |

**미리보기 색깔**:
- 🟢 초록 = 빈 공간 (새 노드)
- 🔵 청록 = 기존 노드 (스냅)
- 🟣 자홍 = 기존 엣지 (분할)

### ✂️ Cut (Shift+E)
엣지 위 클릭으로 노드 삽입 + 엣지 두 개로 분할.

### 🚮 Delete (Shift+R)
| 입력            | 동작                            |
| --------------- | ------------------------------- |
| 엣지 클릭       | 엣지 삭제                       |
| Shift+엣지 클릭 | 양 끝 노드가 고립되면 같이 삭제 |
| 노드 클릭       | 노드 + 연결 엣지 모두 삭제      |

### 🔗 Connect (Shift+T)
두 노드 합치기 (merge).
1. 첫 노드 클릭 → 노란 강조
2. 두 번째 노드 클릭 → 합쳐짐 (첫 노드의 엣지가 둘째 노드로 이동)

### 🎨 Region Paint (Regions 오브젝트 선택 시)
영역 폴리곤 그리기.

| 입력        | 동작                                                        |
| ----------- | ----------------------------------------------------------- |
| 좌클릭      | 점 추가                                                     |
| 우클릭      | 마지막 점 삭제                                              |
| **N**       | 다음 영역으로 순환                                          |
| **Shift+N** | 이전 영역으로 순환                                          |
| Tab         | 다음 영역 (인스펙터 포커스에 따라 안 먹을 수 있음 → N 권장) |
| ESC         | 도구 종료                                                   |

> ⚠️ 키 단축키는 **Scene 뷰를 한 번 클릭한 뒤** 작동합니다. (Unity 표준)

## 4. 실전 워크플로우 예시

### 예시 A: 작은 마을 (5분)

> 목표: 격자 도로 + 작은 집들

1. Alt+Shift+T로 윈도우 열기
2. **Create RoadGraph** 클릭
3. **Test Graphs → "5x5"** 클릭
4. **⚡ Build Blocks + Fill Buildings** → 16개 블록에 박스 빌딩 정렬됨
5. Build Settings에서:
   - Lot Size: 3 (작은 집)
   - Min Height: 2, Max Height: 4 (저층)
6. **⚡** 다시 클릭 → 작은 마을 분위기
7. **💾 Save...** → village_1.json

---

### 예시 B: 영역별 다른 도시 (10분)

> 목표: 중심부는 상업지(높음), 외곽은 주거지(낮음)

1. 5x5 격자 생성
2. **Create Regions** 클릭 → Regions 오브젝트 생성
3. Regions 인스펙터에서 **Add Commercial** 클릭
4. Regions 오브젝트 선택 → **Region Paint** 도구 활성
5. Scene에서 격자 가운데 4칸 정도를 둘러싸는 사각형 폴리곤을 좌클릭 4번으로 그리기 → 주황색 영역 표시됨
6. Regions 인스펙터에서 **Add Residential** 클릭 → Scene 뷰 한 번 클릭 후 **N 키** → 'Residential'로 전환
7. 격자 외곽을 둘러싸는 폴리곤 그리기 → 초록 영역 (Residential)
8. RoadGraph 선택 → **⚡ Build**
   - 가운데 4칸은 큰/높은 빌딩 (Commercial)
   - 나머지는 작은/낮은 빌딩 (Residential)

---

### 예시 C: 자유 편집 도시 (15분)

> 목표: 비격자, 손으로 그린 자연스러운 도시

1. **Create RoadGraph** (빈 상태)
2. **Shift+W**로 Draw 도구 활성
3. Shift 누른 채로 첫 점 클릭 → 둘째 클릭 (45° 스냅으로 깔끔한 도로)
4. Shift+Ctrl 누른 채로 정사각형 4점 + 첫 점 다시 클릭 → 닫힌 사각형 (face 1개 생성)
5. ESC로 끊고, 사각형 안에 대각선이나 분할선 추가
6. **Shift+Q**로 Move 도구 → 노드 한두 개 살짝 옮겨서 비대칭/자연스러움 추가
7. 윈도우 → **Auto Generators → "Jittered 5x5"** 같은 프리셋도 시도해볼 만함
8. **⚡ Build** → 손맛 있는 도시

---

### 예시 D: 방사형 도시 (5분)

1. **Create RoadGraph**
2. **Auto Generators → Radial** 클릭 → 중심 + 8방향 + 3겹 환상도로
3. **⚡ Build**
4. 중앙 광장 효과를 원하면:
   - **Shift+R** (Delete) → 중심 노드 우클릭으로 일부 엣지 삭제
   - 다시 **⚡ Build**

---

### 예시 E: 기존 작업 이어서 (저장/로드)

1. 어제 저장한 town_a.json 준비
2. 윈도우 → **📂 Load...** → town_a.json 선택
3. 그래프 + 영역 + 세팅 모두 복원 + 자동 Build
4. Move/Draw 등으로 수정
5. **💾 Save...** 같은 이름으로 덮어쓰기

## 5. Build Settings 완전 정복

### 📏 Road Inset
face → 블록 줄이는 거리 (도로 폭의 절반).

| 값               | 효과                                    |
| ---------------- | --------------------------------------- |
| 0                | 블록이 도로 한가운데까지 (도로 안 보임) |
| 1.5 (기본)       | 일반 도로 폭 ~3m                        |
| 3+               | 대로                                    |
| face의 절반 이상 | 작은 face는 블록 사라짐                 |

### 📐 Block Thickness
블록 메쉬의 두께 (보도블록 솟아오름).

| 값         | 효과                            |
| ---------- | ------------------------------- |
| 0          | 평면 (도로와 같은 높이)         |
| 0.1 (기본) | 보도블록 살짝 솟음 (자연스러움) |
| 1+         | 단차 큰 도시 베이스             |

### 🏗️ Fill Mode
- **GridOBB**: 블록 전체에 격자로 채움 (큰 블록을 빽빽하게)
- **RoadFacing**: 도로변에 줄지어 정렬 (도시 같은 느낌, 안마당이 빔)

### 📦 Lot Size
빌딩 한 칸 폭 (도로변 따라 측정).

| 값   | 효과                   |
| ---- | ---------------------- |
| 2~3  | 빌딩 많음 (시장, 골목) |
| 4~6  | 일반 주거/상업         |
| 8~12 | 큰 빌딩 (산업단지)     |

> 블록이 작으면 lotSize를 키워도 빌딩 1개로 고정. 큰 블록(긴 변 30m+)에서 차이 명확.

### 📦 Lot Depth (RoadFacing 전용)
빌딩 깊이 (도로 → 안쪽).

### 📐 Lot Margin
칸 안에서 빌딩이 차지하는 비율 (0~0.6).

| 값          | 효과                     |
| ----------- | ------------------------ |
| 0           | 다닥다닥 붙음            |
| 0.15 (기본) | 살짝 간격                |
| 0.5         | 빌딩 사이 간격 큼 (전원) |

### 🏢 Min/Max Height
빌딩 키 랜덤 범위 (m). 한국 1층 ≈ 3m.

### 🎲 Density
각 칸에 빌딩이 생길 확률 (0~1).
- 1: 모든 칸에 빌딩
- 0.5: 절반만 (전원/마을)

### 🎲 Seed
랜덤 시드. 같은 값이면 항상 같은 결과.

### 🏘️ Fill Interior Rows
- OFF: 도로변 1줄만 (안마당 빔)
- ON: 안쪽 3줄까지 (밀집 도시)

## 6. Region 시스템

### 개념
- Region = 영역 폴리곤 + 빌딩 세팅
- 블록의 중심점이 어느 Region에 들어가는지로 매칭
- Region 안: 그 Region의 세팅 + 색깔
- Region 밖: 인스펙터의 fallback 세팅 + 기본 색

### 기본 프리셋
| 버튼            | 색   | Lot Size | Height | Density | 용도           |
| --------------- | ---- | -------- | ------ | ------- | -------------- |
| Add Residential | 초록 | 4        | 3~6m   | 0.85    | 작고 낮은 집   |
| Add Commercial  | 주황 | 5        | 6~16m  | 0.95    | 크고 높은 빌딩 |
| Add Industrial  | 회갈 | 8        | 4~8m   | 0.6     | 큰 창고        |

### 폴리곤 그리기
1. Regions 오브젝트 선택 → Region Paint 도구 활성
2. 좌클릭으로 점 추가 (시계방향 권장)
3. 우클릭으로 마지막 점 삭제
4. **N**으로 다음 Region 전환

### 우선순위
Region 리스트 순서대로 매칭 (먼저 매칭된 게 이김). 폴리곤이 겹치면 위쪽 Region 우선.

## 7. 저장/로드

### 💾 Save (정식)
JSON 파일로 저장. 다음 모두 포함:
- 그래프 (노드 + 엣지)
- Regions (폴리곤 포함)
- Build Settings (Lot Size 등)

### 📂 Load (정식)
- 저장한 모든 것 복원
- **자동으로 Build 실행** → 도시까지 같은 모습으로 복원

### Quick Save / Quick Load
- 다이얼로그 없이 Assets/_TownDoc_quick.json에 즉시 저장/로드
- 빠른 실험에 유용
- 정식 저장 전 백업으로도 활용

### 팁
- 좋은 결과는 명시적 이름으로 Save (town_castle_v3.json)
- JSON이라 텍스트 에디터로 수동 편집 가능
- Git에 텍스트로 들어가 버전 관리 친화적

## 8. 자주 묻는 질문 (FAQ)

**Q. 단축키가 안 먹어요.**
A. **Scene 뷰가 키보드 포커스**를 가져야 합니다. Scene 뷰 빈 공간을 한 번 클릭한 뒤 단축키 사용.

**Q. Region Paint에서 Tab이 안 먹어요.**
A. Unity의 Tab은 인스펙터 포커스 이동 단축키라 자주 가로챕니다. 대신 **N 키**를 쓰세요 (Shift+N으로 역방향).

**Q. Lot Size를 바꿔도 빌딩 개수가 안 변해요.**
A. 블록이 너무 작으면 count=1로 고정됩니다. 큰 face(긴 변 30m+)에서 테스트하세요.

**Q. 빌딩이 도로 위로 삐져나와요.**
A. **Road Inset**을 키워보세요 (1.5 → 2.5).

**Q. 영역(Region) 폴리곤을 그리는데 점이 안 찍혀요.**
A. **Regions 오브젝트가 선택**되어 있는지 확인. (RoadGraph가 아니라!)

**Q. 같은 face가 인스펙터에는 inner=1인데 블록이 안 생겨요.**
A. **Road Inset이 face보다 큼**. 인셋이 너무 크면 폴리곤이 자기교차해서 자동 폐기됩니다. Inset을 줄이세요.

**Q. 도로 그래프를 다른 사람과 공유하고 싶어요.**
A. Save한 JSON 파일을 공유. 받은 사람은 Load하면 끝.

**Q. v1.x와 같이 쓸 수 있나요?**
A. 네. 별도 컴포넌트(RoadGraphAuthoring)라 충돌 없음. 같은 씬에서 v1, v2 둘 다 사용 가능.

**Q. 블록을 손으로 수정하고 싶어요.**
A. 현재는 자동 생성만 지원. ProBuilder 통합은 향후 옵션.

**Q. Clear ALL 했는데 Region 폴리곤이 남아요.**
A. v2.0.x 이전 버전. 최신 코드에선 Clear ALL 시 Region 폴리곤도 비워집니다 (Region 정의는 보존). Region 정의까지 통째로 삭제하려면 Regions 인스펙터의 **Remove All Regions** 사용.

## 9. 트러블슈팅

### "EndLayoutGroup: BeginLayoutGroup must be called first" 에러
보통 dialog 호출이 GUI 도중 실행돼서 발생. 모든 dialog 호출은 EditorApplication.delayCall로 한 프레임 미루도록 처리되어 있음. 그래도 발생하면 Console stack trace 첨부해 보고.

### Undo 후 이상한 동작
RoadGraphAuthoring.OnUndoRedo에서 캐시 무효화 처리됨. 그래도 이상하면 다른 도구로 한 번 전환했다가 돌아오면 갱신됨.

### face 카운트가 0인데 도로는 그려져 있음
**닫힌 사이클이 없다**는 뜻. 사각형 그리려면 마지막 점을 첫 점에 스냅(클릭)해야 닫힘. 미리보기가 청록색일 때 클릭.

### 단축키 충돌 다이얼로그가 떴음
Edit → Shortcuts 메뉴에서 충돌 해결. 또는 ToolShortcuts.cs에서 키 변경.

### 도시가 너무 칙칙
현재 박스 빌딩이라 한계. 빌딩 프리팹 시스템(v2.1 예정)을 활성화하면 다양한 모델 사용 가능. 임시로는 Region 색깔을 다양하게.

### 빌드 시 에러
Editor 폴더에 있는 코드는 빌드에 안 포함되니 안전. Scripts/V2의 코드 중 #if UNITY_EDITOR 가드가 필요한 부분은 모두 처리되어 있음.

### Inspector에 Lot Size 등이 안 보임
RoadGraph Authoring 컴포넌트 클릭 후 위쪽 컴포넌트 헤더 옆 ▶를 펼쳐야 보입니다. 또는 윈도우(Alt+Shift+T)에서 작업.

## 10. 부록: 알려진 한계

- **블록 폴리곤 인셋**은 단순 알고리즘. 매우 복잡한 오목 폴리곤은 깨질 수 있음 (자동 폐기됨)
- **Region 폴리곤 시각화**가 볼록일 때만 정확. 오목 폴리곤은 채움 색이 깨질 수 있음 (외곽선은 항상 정상)
- **Region 폴리곤이 여러 개 겹칠 때** 우선순위는 리스트 순서
- **빌딩 충돌 검사**는 OBB 근사. 매우 좁은 face에서 부정확할 수 있음
- **자동 Build는 명시적**: 저장/로드 외엔 자동 갱신 안 함. 도로 편집 후 직접 ⚡ 눌러야 함
- **곡선 도로 미지원**: 직선 엣지만 가능. 휘어진 도로는 노드를 여러 개 박아야 함 (v2.1 예정)
- **도로 자체가 시각화 안 됨**: 그래프 선만 보임. 진짜 도로 메쉬는 v2.1 예정
- **Y축은 평면 가정**: Terrain과 통합되지 않음
